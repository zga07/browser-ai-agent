# AI Autonomous Browser Agent

Автономный веб-агент на базе **Playwright** и **LLM Tool Calling**, способный выполнять сложные многошаговые сценарии в реальных веб-приложениях (hh.ru, Gmail, сервисы доставки еды, маркетплейсы) без жестко захардкоженной логики под конкретные сайты.

---

## 🌟 Ключевые возможности

* **Zero-Hardcode Архитектура:** Агент не полагается на жестко прописанные CSS-классы, селекторы или домены. Ориентация в интерфейсе строится на семантике элементов, ролях доступности (WAI-ARIA) и текстовом содержимом.
* **Set-of-Mark (DOM Grounding):** Динамическая разметка интерактивных элементов числовыми индексами `[ID]` прямо в DOM с последующим координатным кликом через эмуляцию реального курсора мыши.
* **Принудительный ReAct (Observation → Reasoning → Plan):** Перед каждым действием агент формулирует мыслительный шаг, что предотвращает слепые клики и галлюцинации при смене состояний экрана.
* **Human-in-the-Loop Security Layer:** Встроенный перехватчик потенциально опасных действий (оплата, списание средств, оформление заказа, удаление профиля), запрашивающий подтверждение у пользователя в терминале перед отправкой события в браузер.
* **Однооконный режим и контроль вкладок:** Принудительная нейтрализация `target="_blank"` и перехват `window.open` предотвращают неконтролируемое открытие десятков фоновых окон.
* **Сохранение сессий:** Использование `launch_persistent_context` с локальным профилем браузера — не нужно логиниться заново при каждом перезапуске.

## 🏗 Архитектура проекта

```text
├── main.py              # Точка входа, интерактивный CLI интерфейс (Rich)
├── agent.py             # ReAct-оркестратор, системный промпт, сжатие контекста
├── browser_engine.py    # Playwright-рантайм, физические клики, ввод текста, скролл
├── dom_processor.py     # JS-сканер Set-of-Mark, фильтрация шума, приоритизация модалок
├── tools.py             # Спецификация инструментов (OpenAI Tools Schema) и Security Layer
├── browser_profile/     # Директория профиля Chromium (куки, авторизации)
└── screenshots/         # Сохраняемые снимки экранов перед финализацией задач
```

### Модули под капотом

| Модуль | Назначение |
| :--- | :--- |
| **`dom_processor.py`** | Внедряет в страницу легковесный JS-скрипт, фильтрует декоративный шум (`img`, `svg`, `tooltip`), типизирует поля ввода (`input-text`, `radio`, `checkbox`) и поднимает элементы открытых модальных окон в приоритет разметки. |
| **`browser_engine.py`** | Управляет жизненным циклом Chromium. Вычисляет координаты `(x, y)` центра элементов для обхода перекрытий, эмулирует физическое колесо мыши для SPA со вложенным скроллом и обеспечивает fallback-ввод текста через эмуляцию клавиатуры. |
| **`tools.py`** | Объявляет интерфейс тулов для LLM (`click_element`, `type_text`, `scroll_page`, `go_back`, `press_key`, `finish_task`) и проверяет действия по белому списку безопасности. |
| **`agent.py`** | Ведет диалог с языковой моделью, исключает параллельные вызовы (`parallel_tool_calls=False`) для устранения race conditions в DOM и формирует строгий структурированный отчет `completed_items`. |

## 🚀 Быстрый старт

### 1. Требования
* Python 3.11+
* Установленный Google Chrome или системные зависимости Chromium

### 2. Установка зависимостей

```bash
git clone [https://github.com/zga/browser-ai-agent.git](https://github.com/zga/browser-ai-agent.git)
cd browser-ai-agent

python3 -m venv venv
source venv/bin/activate

pip install -r requirements.txt
playwright install chromium
```

*(Если `requirements.txt` еще не сгенерирован: `pip install playwright openai python-dotenv rich`)*

### 3. Настройка окружения

Создай файл `.env` в корне проекта:

```env
OPENAI_API_KEY="your-api-key"
OPENAI_BASE_URL="[https://api.openai.com/v1](https://api.openai.com/v1)"   # Либо URL прокси/локального провайдера
MODEL_NAME="gpt-4o-mini"                      # Поддерживаются gpt-4o, claude-3-5-sonnet и аналоги
```

### 4. Запуск агента

```bash
python main.py
```

При первом запуске откроется окно Chromium. Ты можешь авторизоваться в нужных сервисах (Google, hh.ru, сервисы доставки) руками — сессия сохранится в папке `./browser_profile/` и останется активной при последующих запусках.

## 🛡 Безопасность (Security Layer)

Агент снабжен барьером защиты от неконтролируемых действий. Если модель пытается вызвать команду с описанием, содержащим критические паттерны:
* Оформление и оплата заказа
* Списание денег / перевод
* Необратимое удаление данных

Выполнение в браузере приостанавливается, а в терминале выводится предупреждение:

```text
⚠️  [SECURITY LAYER] Обнаружено критическое действие:
👉 Действие: подтвердить заказ в корзине
Подтвердить выполнение этого шага? (yes/no):
```

## 🛠 Особенности реализации (Engineering Notes)

* **Устранение `Stale Element Reference`:** После каждого клика или перезагрузки страницы кэш `elements_cache` очищается, принуждая агента запрашивать свежий срез через `query_dom`.
* **Сжатие контекста токенов:** В истории сообщений хранится развернутым только последний срез DOM. Все предыдущие тяжелые текстовые списки интерактивных элементов сворачиваются в плейсхолдер `[Срез DOM обработан ранее]`, сохраняя доступный лимит контекста даже на 50+ шагах.
