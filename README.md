# Autonomous AI Browser Agent

Автономный веб-агент на базе **Python**, **Playwright** и архитектуры **ReAct + DOM Sub-agent**, способный исследовать страницы в реальном времени, взаимодействовать с элементами интерфейса и выполнять сложные многошаговые сценарии в браузере.

---

## Архитектура и ключевые инженерные решения

### 1. Двухуровневая модель: DOM Sub-agent (Экономия контекста)
* **Проблема:** Передача полного HTML-дерева страницы в LLM сжигает десятки тысяч токенов за один шаг, создает визуальный шум и часто приводит к галлюцинациям в селекторах.
* **Решение:** Легковесный JS-экстрактор собирает срез исключительно видимых и интерактивных элементов (`button`, `input`, `a`, `role="button"`), фильтруя оверлеи. Вспомогательный **DOM Sub-agent** анализирует выжимку и транслирует намерение главного агента в точные, стабильные Playwright-селекторы (`text="...", [aria-label="..."]`).
* **Результат:** Снижение расхода токенов на 85–90% на каждый шаг принятия решений.

### 2. Security Layer (Human-in-the-Loop)
* Для действий, связанных со списанием средств, оформлением заказов или удалением данных (`checkout`, `pay`, `купить`, `оформить заказ`), агент принудительно останавливает автоматическое выполнение и запрашивает явное подтверждение пользователя в терминале `(yes/no)`.

### 3. Persistent Browser Context (Сохранение сессий)
* Агент запускается в постоянном контексте (`user_data_dir`). Куки, авторизация, выбранные адреса доставки и гео-настройки сохраняются между перезапусками, исключая повторные блокировки и капчи.

### 4. Отказоустойчивость и троттлинг
* Встроенная обработка `RateLimitError` (HTTP 429) с адаптивным backoff-ожиданием.
* Fallback-клик (`force=True`) для элементов, временно перекрытых динамическими всплывающими плашками.

## Стек технологий

* **Язык:** Python 3.11+
* **Браузерная автоматизация:** Playwright (Synchronous API)
* **LLM Engine:** OpenAI-compatible API (Google AI Studio: Gemini 3.5 Flash Lite или другие)
* **CLI & Logging:** Rich

## Установка и запуск

### 1. Клонирование и установка зависимостей

```bash
git clone <url-твоего-репозитория>
cd browser-ai-agent
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
playwright install chromium
```

### 2. Настройка переменных окружения

OPENAI_API_KEY=your_api_key_here
OPENAI_BASE_URL=[https://generativelanguage.googleapis.com/v1beta/openai/](https://generativelanguage.googleapis.com/v1beta/openai/)
MODEL_NAME=gemini-3.5-flash-lite

### 3. Запуск

```bash
python main.py
```
